# 1.4 Operadores

> 📚 Los operadores son **símbolos que hacen cosas** con los valores: sumar, comparar, combinar, etc.

---

## Operadores Aritméticos

Para hacer **operaciones matemáticas**, como en la calculadora.

| Operador | Significado               | Ejemplo  | Resultado |
| -------- | ------------------------- | -------- | --------- |
| `+`      | Suma                      | `5 + 3`  | `8`       |
| `-`      | Resta                     | `5 - 3`  | `2`       |
| `*`      | Multiplicación            | `5 * 3`  | `15`      |
| `/`      | División                  | `10 / 2` | `5`       |
| `%`      | Módulo (resto de dividir) | `10 % 3` | `1`       |
| `**`     | Potencia (elevado a)      | `2 ** 3` | `8`       |

```javascript
let suma = 10 + 5; // 15
let resto = 17 % 5; // 2  (sobra 2 al dividir 17/5)
let potencia = 2 ** 10; // 1024
```

> 💡 **El módulo `%`** sirve mucho para saber si un número es par (`n % 2 === 0`) o impar.

### El `+` también une textos

```javascript
"Hola " + "mundo"; // "Hola mundo"
"Edad: " + 40; // "Edad: 40"
```

## Operadores de Comparación

Sirven para **comparar valores** y siempre devuelven `true` o `false`.

| Operador | Significado                 | Ejemplo     | Resultado  |
| -------- | --------------------------- | ----------- | ---------- |
| `==`     | Igual (sin importar tipo)   | `5 == "5"`  | `true` ⚠️  |
| `===`    | Igual estricto (mismo tipo) | `5 === "5"` | `false` ✅ |
| `!=`     | Diferente                   | `5 != "5"`  | `false`    |
| `!==`    | Diferente estricto          | `5 !== "5"` | `true`     |
| `>`      | Mayor que                   | `10 > 5`    | `true`     |
| `<`      | Menor que                   | `10 < 5`    | `false`    |
| `>=`     | Mayor o igual               | `10 >= 10`  | `true`     |
| `<=`     | Menor o igual               | `5 <= 10`   | `true`     |

### `==` vs `===` (MUY importante)

- **`==`**: compara **solo el valor**, convirtiendo tipos si hace falta. Confuso.
- **`===`**: compara **valor Y tipo**. Más seguro y predecible.

```javascript
5 == "5"; // true  → convierte tipos antes de comparar
5 === "5"; // false → 5 es número, "5" es string
```

> 🎯 **Regla de oro:** Usa siempre `===` y `!==`. Olvídate de `==` y `!=`.

## Operadores Lógicos

Se usan para **combinar condiciones**.

### `&&` (Y / AND) — todas deben ser verdaderas

```javascript
let edad = 40;
let tienePase = true;
if (edad >= 18 && tienePase) {
  console.log("Puede entrar"); // ✅
}
```

### `||` (O / OR) — basta con que una sea verdadera

```javascript
let esFinDeSemana = true;
let esFeriado = false;
if (esFinDeSemana || esFeriado) {
  console.log("Día libre"); // ✅
}
```

### `!` (NO / NOT) — invierte el valor

```javascript
let estaLloviendo = false;
if (!estaLloviendo) {
  console.log("Puedes salir"); // ✅
}
```

## Operadores Modernos

### Optional Chaining `?.`

Permite acceder a propiedades **sin que explote el código** si algo es `undefined` o `null`.

```javascript
let persona = { nombre: "Ana" };

console.log(persona.direccion.calle); // ❌ Error: no existe "direccion"
console.log(persona.direccion?.calle); // ✅ undefined (sin error)
```

### Nullish Coalescing `??`

Devuelve el valor de la **derecha** solo si el de la izquierda es `null` o `undefined`.

```javascript
let nombre = null;
let mostrar = nombre ?? "Invitado";
console.log(mostrar); // "Invitado"

let edad = 0;
console.log(edad ?? 18); // 0 → porque 0 no es null ni undefined
console.log(edad || 18); // 18 → porque 0 es falsy (diferente de ??)
```

### Operador Ternario `? :`

Un `if/else` corto en una sola línea.

```javascript
let edad = 40;
let mensaje = edad >= 18 ? "Adulto" : "Menor";
console.log(mensaje); // "Adulto"

// Equivalente a:
// if (edad >= 18) { mensaje = "Adulto"; } else { mensaje = "Menor"; }
```

## Operadores Avanzados

### Spread Operator `...` (Desplegar)

**Desempaca** los elementos de un array u objeto.

```javascript
let numeros = [1, 2, 3];
let masNumeros = [...numeros, 4, 5]; // [1, 2, 3, 4, 5]

let persona = { nombre: "Ana", edad: 40 };
let copia = { ...persona, ciudad: "Lima" };
// { nombre: "Ana", edad: 40, ciudad: "Lima" }
```

### Rest Operator `...` (Recoger)

**Junta** varios valores en un array. Mismo símbolo, distinto uso.

```javascript
function sumar(...numeros) {
  return numeros.reduce((a, b) => a + b, 0);
}
sumar(1, 2, 3, 4); // 10
```

> 💡 **Truco:** Si `...` está al **definir** (función o destructuring) → es **rest**. Si está al **usar** → es **spread**.

### Bitwise Operators (a nivel de bits)

Operan sobre los **bits** (unos y ceros) de los números. Uso avanzado, raro en programación cotidiana.

| Operador | Nombre          |
| -------- | --------------- |
| `&`      | AND a bit       |
| `\|`     | OR a bit        |
| `^`      | XOR a bit       |
| `~`      | NOT a bit       |
| `<<`     | Shift izquierda |
| `>>`     | Shift derecha   |

```javascript
5 & 3; // 1
5 | 3; // 7
```

### Operadores Unarios

Aplican una operación a **un solo valor**.

```javascript
let n = 5;
n++; // Incrementa: 6
n--; // Decrementa: 5
-n; // Negativo: -5
+"42"; // Convierte a número: 42
!true; // Negación: false
typeof n; // "number"
delete obj.prop; // Borra propiedad de objeto
```

## 📝 Notas importantes

> 💡 **Nota:** El operador `+` con textos los une (concatena). Con números los suma. Cuidado al mezclar.

> ⚠️ **Observación:** Usa **siempre `===` y `!==`**, nunca `==` o `!=`. Evita errores difíciles de detectar.

> 🎯 **Diferencia clave entre `??` y `||`:**
>
> - `||` considera **falsy** (0, "", null, undefined, NaN, false).
> - `??` solo considera **null y undefined**.

---

## ✅ Resumen

- **Aritméticos:** `+ - * / % **` para matemáticas.
- **Comparación:** usa siempre `===` y `!==`.
- **Lógicos:** `&&` (y), `||` (o), `!` (no).
- **Modernos:** `?.` (acceso seguro), `??` (valor por defecto), `? :` (if corto).
- **Spread `...`** despliega; **Rest `...`** recoge.
- Hay también operadores **bitwise** y **unarios** para casos especiales.
