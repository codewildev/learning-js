## ¿Qué es JavaScript?

Imagina una página web como una casa: **HTML** son las paredes (estructura), **CSS** es la pintura y decoración (estilo), y **JavaScript** es la electricidad y las cosas que se mueven (interruptores, luces, electrodomésticos). JavaScript es el lenguaje que le da **vida e interactividad** a las páginas web: botones que reaccionan al hacer clic, formularios que validan datos, animaciones, etc.

### Historia rápida

- Creado en **1995** por Brendan Eich en solo 10 días, para la empresa Netscape.
- Inicialmente se llamó _Mocha_, después _LiveScript_ y finalmente _JavaScript_.
- Hoy es uno de los lenguajes más usados del mundo.

### ECMAScript

**ECMAScript (ES)** es el "estándar" o "reglamento oficial" sobre cómo debe funcionar JavaScript. Piénsalo como las reglas oficiales del fútbol: distintos países juegan, pero todos siguen las mismas reglas.

- **ES5 (2009):** versión antigua, todavía soportada en navegadores viejos.
- **ES6 / ES2015 en adelante:** la versión moderna, con muchas mejoras. Se actualiza cada año (ES2016, ES2017, ES2024, etc.).

### Motores de JavaScript

Son programas que **leen y ejecutan** el código JavaScript. Cada navegador trae el suyo:

| Motor              | Usado por                    |
| ------------------ | ---------------------------- |
| **V8**             | Google Chrome, Node.js, Edge |
| **SpiderMonkey**   | Firefox                      |
| **JavaScriptCore** | Safari                       |

### JavaScript vs Java ⚠️

**No son lo mismo**, aunque sus nombres se parecen. Es como comparar _jamón_ con _Jamaica_: solo comparten letras.

- **Java:** lenguaje robusto, usado para aplicaciones empresariales, Android.
- **JavaScript:** lenguaje del navegador y web, más flexible.

### Single Thread y Non-blocking

- **Single Thread (un solo hilo):** JavaScript hace **una cosa a la vez**, como un cocinero que solo tiene un sartén.
- **Non-blocking (no bloqueante):** aunque solo tiene un sartén, puede dejar algo cocinándose mientras pica verduras. Es decir, no se queda esperando; sigue trabajando en otras tareas mientras una termina.

---

## ✅ Resumen

- JavaScript le da **interactividad** a las páginas web.
- Sigue el estándar **ECMAScript (ES)**, hoy en su versión moderna ES6+.
- Se ejecuta en **navegadores** y en **Node.js** gracias a motores como **V8**.
- Es **diferente de Java**.
- Es **single thread pero no bloqueante**: hace una cosa a la vez, pero sin quedarse esperando.
