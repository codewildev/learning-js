## ¿Dónde se ejecuta JavaScript?

### 🌐 Navegador

El lugar original. Cuando abres una página web, el navegador ejecuta el JavaScript de esa página.

### 💻 Node.js

Es un programa que permite ejecutar JavaScript **fuera del navegador**, directamente en tu computadora. Sirve para construir servidores, herramientas, aplicaciones de escritorio, etc.

### 🛠️ Runtime environments

Un **runtime** es simplemente el "entorno" donde corre el código. JavaScript tiene varios:

- **Navegador** (Chrome, Firefox…)
- **Node.js** (servidor)
- **Deno, Bun** (alternativas modernas a Node.js)
